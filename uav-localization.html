UAV Localization in GNSS‑Denied Environments

Prince Sultan University (2024‑2025)

This project investigates robust UAV positioning when GNSS signals are unavailable or degraded. We combine sensor‑fusion (IMU, visual odometry, LiDAR) with AI/ML techniques (deep neural networks, GRU predictors) to deliver accurate localization for autonomous aerial missions.

Key Contributions

  • Design of a GNSS‑denied navigation stack built on ROS 2.
  • Integration of Kalman filtering with learning‑based predictors for drift correction.
  • Creation of the FLIGHTGEN dataset for training and benchmarking.
  • Open‑source release of the navigation framework on GitHub.
